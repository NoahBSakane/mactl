# ルール提案の受け箱

各エージェントが「指示ファイルに足したい・変えたい」と思ったルールを、**直接編集せずに**ここへ追記する。全体に行き渡らせるか、固有のルールにするか、却下するかは、`triage-rules` skill で検討し、ユーザーの承認を得て決める。追記専用で、既存のエントリは書き換えない(状態の行だけ、検討時に更新する)。

提案は `propose-rule` skill で、次の書式で追記する。

```markdown
## 2026-10-07 claude — 提案: (一行の要約)

- 提案文: (命令形で1〜3行。そのまま指示ファイルに入れられる文)
- 動機: (何が起きたか。秘密・個人情報は書かない。出典があれば添える)
- 想定範囲: 全体 / 固有:(エージェント名) / プロジェクト:(パス) / 知識:(領域) — (理由)
- 状態: 未検討
```

状態は、検討後に次のいずれかへ変える。

- `採用(行き先, 日付)`: 行き先は、`src/shared-rules.md`、`src/claude-user.md`、`src/codex-persona.md`、プロジェクトの `AGENTS.md`、`~/.knowledge/<領域>.md` など。
- `却下(理由)`: 既存のルールと重複・矛盾する、範囲が狭すぎる、など。
- `統合(提案名)`: 他の提案とまとめた。
