# 引き継ぎ(`.agent-handoff/STATE.md`)

長時間のタスクでは、作業ディレクトリ(プロジェクトのルート)の `.agent-handoff/STATE.md` を、**節目ごと**(計画が決まった時、1つ区切りが付いた時、重要な判断をした時)に更新する。エージェントが使えなくなった時(使用上限など)に、別のエージェントがここから引き継ぐための唯一の足場になるので、上限到達後には書けない前提で、先に書いておく。

## 書式

```markdown
# STATE(更新: 2026-10-06 19:30 / 担当: claude)

## 目的
(1〜3行。何を達成すれば完了か)

## 確定した決定
- (決定と理由。後から覆さないもの)

## 変更ファイル
- path — 何をしたか

## 検証結果
- 実行したテスト/コマンドと結果(未検証なら未検証と書く)

## 残タスク
- [ ] ...

## 次の一手
(次に着手すること1つ)

## 使用中の構成
(誰に何を任せていて、何が実行中か)
```

## 運用

- 初回作成時に `.git/info/exclude` に `.agent-handoff/` を追記して、gitの管理対象から外す(リポジトリを汚さない)。編集ツールで書いたときは hook(`handoff-exclude-hook.sh`)が自動で追記する。
- 引き継ぎ側は最初に `~/AGENTS.md` の共通ルールと `STATE.md` を読み、「次の一手」から再開する。書かれていないことは推測せず、確認が必要なら質問する(お風呂モード中は推奨案で進める)。
- 作業が完了したら `STATE.md` の先頭に「完了」と書き、残タスクを空にする。
